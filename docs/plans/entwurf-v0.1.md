# Entwurf v0.1 开发计划：本机 GPT 驱动的可验证视觉知识编译器

## 1. 产品定义与成功标准

- 定位：Windows 本地优先的个性化知识可视化工具。输入教材与参考风格，输出可追溯、可编辑、可校验的高密度知识图。
- 核心流程：资料解析 → Knowledge IR → GPT 知识规划与视觉方案 → Rust 本地编译 → 自动校验 → 确定性局部修复 → SVG/PNG/PDF。
- 用户：使用 Windows 10/11 x64、已登录 ChatGPT 桌面应用的个人学习者与知识工作者。
- 首版边界：专注知识图；不提供通用聊天、演示文稿、CLI、MCP、Obsidian 同步、本地大模型或自动更新。
- 离线要求：除 GPT 规划与生图外，导入、解析、IR 编辑、编译、校验、导出均完全离线可用。
- 完成标准：真实概率论章节可在默认 A3 横向、最多 3 页内完成端到端生成；所有关键节点可追溯；公式无静默改动；SVG/PNG/PDF 可稳定导出；GPT 自动化通过兼容性门槛后才允许开启。
- 项目约束：项目名 Entwurf，Apache-2.0，简体中文界面，英文代码/IR 字段；仅本地数据，无遥测。

## 2. 架构与核心契约

- 技术栈：Tauri 2 + React + TypeScript + Vite；Rust 工作区承载解析、IR、布局、验证、存储和任务状态机；Windows 自动化由自包含 .NET 10 C# sidecar 实现。
- 目录职责：apps/desktop 放 Tauri/React；crates/* 放核心能力；sidecars/gpt-bridge 放 FlaUI/UIA 适配器；JSON Schema 与生成的 TS/Rust 类型共享同一份 packages/contracts。
- 文档处理：PDF 使用 PDFium（BSD），优先文字层，扫描页渲染后交给本机 Tesseract chi_sim+eng；Markdown 使用 CommonMark 解析；LaTeX 保留章节、环境与公式原文，不做完整宏展开；图片作为 OCR 来源。缺失 Tesseract 时明确降级，不伪造识别结果。
- 排版与导出：Rust 负责确定性分组、装箱、连线与碰撞检测；Typst 负责文字、数学公式排版和 PDF；SVG 是权威矢量页面，PNG 由 SVG 栅格化生成，PDF 与 SVG 共用同一场景。默认 A3 横向，支持自动分页。
- 持久化：每个项目包含 SQLite（WAL）与文件目录，保存素材、不可变任务版本、IR、风格、校验报告、导出物和审计日志；源文件复制入项目并按内容哈希去重。
- Knowledge IR：包含 SourceAnchor（文件、页、字符/区域、引用哈希）、KnowledgeNode（概念/定义/公式/定理/例题/警告）、GraphEdge、Violation/Correction 与验证状态。所有节点必须带来源或明确标记“待确认”。
- GPT 契约：发送端使用 TaskEnvelope（任务/版本、资料摘要、基线 IR 摘要、风格、画布、输出 Schema）；接收端使用 ResultEnvelope（同任务/版本身份、知识补丁、视觉计划、纠错记录、图片引用）。JSON 无效最多纠正重试一次，再失败转人工。
- 知识权威：本地解析结果是基线；GPT 可补充知识与提出纠错。纠错可自动采纳，但必须保存原文、候选、理由、来源和时间，并支持单条撤销。任何静默覆盖都视为校验失败。
- 任务状态机：DRAFT → INGESTING → IR_READY → PROMPT_READY → SENDING → WAITING → IMPORTING → COMPILING → VERIFYING → NEEDS_REVIEW | APPROVED → EXPORTED，旁路状态为 PAUSED / FAILED / CANCELLED。
- Sidecar 协议：Rust 与 C# 通过命名管道、带长度前缀的 JSON-RPC 通信；暴露 detect_app、attach、start_conversation、paste_prompt、submit、observe、capture_text、watch_artifact、pause、cancel。管道仅限当前用户，启动时交换一次性会话令牌。
- 公开接口范围：v0.1 不暴露网络 API、HTTP MCP 或公共 CLI；上述 JSON Schema、IPC 事件和项目文件格式是唯一稳定契约。

## 3. 产品界面与 GPT 自动化

- 五页工作台：项目、资料与风格、任务、结果、设置；项目内任务按章节组织，每个任务保留独立版本链。
- classic 视觉：左侧 230px 导航栏、1120px 内容列、40px 面包屑、28px 细网格背景、轻玻璃侧栏与极简线条；React 重新实现，不复制 Vue 组件。
- 主题：深色使用纯黑底、#e0e0e0 正文、#9b3dff 强调；浅色使用纯白底、黑色正文、#8f35ff 强调。两者均内置 LXGW WenKai 字体并附 OFL 许可证。
- 侧栏内容：Entwurf 文字标识与项目导航为主，不保留个人头像或站点装饰动画。
- 首次配置：检测 ChatGPT 桌面应用、WebView 可访问性、Tesseract 与导入目录；生成能力报告。自动化不可用时仍可直接进入人工辅助模式。
- 自动运行：用户每次显式点击开始；Entwurf 启动并置前 ChatGPT、创建独立对话、粘贴完整 TaskEnvelope、提交、观察生成状态。一次只运行一个任务；用户切走窗口、锁屏、应用更新或结构不匹配时立即暂停。
- 完成判定：同时要求生成控件进入完成态、输出区域稳定、计划 JSON 可解析、图片文件或保存动作可确认；不使用固定睡眠作为完成依据。
- 结果回收：优先通过可访问控件复制文本；图片监听用户授权的 imports/ 与选定下载目录。导入后按任务 ID、版本、哈希重命名为 entwurf-task-<id>-v<n>-plan.json 和 ...-image.<ext>；无法唯一归属时要求选择，不猜测。
- 合规边界：不读取 Cookie、不调用私有接口、不绕过登录/验证码/额度、不在后台无人值守运行、不做坐标盲点点击。无法获得可观测控件时暂停并显示“复制提示 / 打开 ChatGPT / 导入文件”操作卡。
- 发布门槛：自动化必须先在目标 ChatGPT 应用版本上通过“发现窗口、可靠输入、可靠完成判定、可靠取回”四项验收；否则保持实验性隐藏/默认关闭，核心知识图功能仍可发布。
- 结果编辑：支持修改节点文本、公式、来源锚点、重要度与画布顺序；手工修改单独存储，重新生成不得覆盖。结果页提供并排/滑动版本比较及内容差异报告。
- 确定性修复：允许调宽节点、换行、缩放字号、重排分组、绕线和自动分页，最多 3 轮；不得改写知识内容。可在版本级或单条修复级回滚。
- 导出：输出 SVG、300 DPI PNG、A3 矢量 PDF、manifest.json 和可重新导入的 knowledge.ir.json；PNG 仅作预览，PDF/SVG 始终由当前批准 IR 编译。

## 4. 实施顺序与提交边界

1. 基础工程：建立 Windows 原生构建工作树；安装并检测 Rust/MSVC、.NET 10、WebView2、Tesseract、Node；初始化工作区、Apache-2.0 LICENSE、README、CONTRIBUTING、CHANGELOG、SECURITY、.gitignore 和 Windows 构建脚本。
2. 契约与存储：落地 JSON Schema、生成的类型、SQLite 迁移、项目目录、状态机和审计事件；以契约测试锁定兼容性。
3. GPT Bridge 技术验证：实现 C# sidecar 与应用发现；尝试通过 WebView2 可访问性能力读取控件。先证明输入、发送、完成检测和文本取回，再接图片保存监听；未达到四项门槛即停止自动化扩展，不进入盲控。
4. 资料摄取：完成 PDF、Markdown、图片 OCR、LaTeX 导入；生成带来源锚点的 Knowledge IR；加入中文/英文 OCR、公式待确认队列、重复素材哈希和解析诊断。
5. 编译器：实现 A3 画布、章节分组、高密度装箱、正交连线、分页、Typst 文本/公式排版、SVG/PNG/PDF 导出及渲染缓存。
6. 校验与修复：加入 Schema、来源一致性、公式规范化、内容覆盖率、越界、重叠、最小字号、对比度与导出完整性检查；实现确定性修复和回滚。
7. 桌面 UI：按 classic 规范实现五页工作台、深浅主题、首次配置、知识节点编辑、任务日志、人工接管卡和版本比较；接入核心与 sidecar。
8. 端到端闭环：接入 TaskEnvelope 生成、GPT 结果导入、一次纠正重试、任务版本、局部重算和导出；保证断网时除 GPT 调用外均可工作。
9. 发布硬化：构建未签名 Windows x64 NSIS 安装包；完成安装/卸载、路径含中文/空格、DPI 与多显示器测试；生成第三方许可证清单和脱敏诊断包；建立多阶段本地提交，不推送远端。

## 5. 测试、验收与默认假设

- 自动测试：Rust 单元/集成测试覆盖解析、IR、Schema、状态机、布局、分页、校验、修复回滚和离线路径；C# 测试覆盖管道协议、前台保护、DPI 归一化、文件监听与失败停机；React 测试覆盖关键交互。
- 黄金样本：仓库提供可公开的合成中文概率论样本用于 CI；真实 PDF 与手写参考图放入 .gitignore 排除的 fixtures/private/，由本地验收脚本读取。
- 视觉回归：五页在 1280×800 与 1920×1080、100%/125%/150% 缩放下生成深/浅主题截图基线，检查侧栏宽度、网格、字体层级、焦点态和文本对比度；目标是继承 classic 语言，不要求像素级复刻站点。
- 内容门禁：所有 critical 节点和章节标题必须有来源；所有公式必须精确匹配来源或存在完整可撤销的纠错记录；不得有未确认公式、节点重叠、文本裁切或低于 A3 打印 8pt 的可读内容。
- 端到端验收：私有概率论章节必须保留全部核心结构、在最多 3 页 A3 内完成布局、通过内容与版式校验、成功导出三种格式，并在重新生成后保留手工修改。
- 自动化验收：仅在真实 Windows 前台会话验证；覆盖应用未启动、登录失效、更新后结构变化、用户切窗、下载目录歧义、超时和取消。任一门禁失败必须可安全暂停且不丢草稿。
- 安装验收：全新用户配置下安装、启动、检测 Tesseract、创建项目、重建数据库、卸载重装；断网启动核心功能；无遥测请求。
- 默认假设：首版仅 Windows x64；自动化实验性默认关闭；不采用坐标盲控；不依赖 DSH ChatGPT Bridge 或任何 API Key；PDF 库选择必须与 Apache-2.0 兼容；Tesseract 由用户安装并由应用检测；不做代码签名和自动更新
