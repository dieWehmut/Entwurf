# 概率论：随机变量与条件概率

## 1. 随机变量

定义 1.1：设样本空间为 Ω。随机变量 X 是从 Ω 到实数集 ℝ 的可测函数。随机变量把每个试验结果映射为一个实数，因此可以用分布函数描述其统计规律。

定义 1.2：随机变量 X 的分布函数为 F_X(x) = P(X ≤ x)。分布函数右连续、单调不减，并且满足 F_X(-∞) = 0 与 F_X(+∞) = 1。

$$P(X \le x) = F_X(x)$$

## 2. 条件概率

定义 2.1：当 P(B) > 0 时，事件 A 在事件 B 已发生条件下的条件概率定义为

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$$

条件概率仍然是概率：它对互斥事件可加，并满足 P(Ω | B) = 1。条件概率用于把新的观测信息纳入原有概率模型。

## 3. 全概率公式

定理 3.1：若事件 B_1, B_2, …, B_n 构成样本空间的一个划分，且每个 P(B_i) > 0，则对任意事件 A，

$$P(A) = \sum_{i=1}^{n} P(A \mid B_i) P(B_i)$$

全概率公式把一个复杂事件按互斥情形拆分，再分别计算条件概率。

## 4. 贝叶斯公式

定理 4.1：在条件概率有定义时，

$$P(B_i \mid A) = \frac{P(A \mid B_i) P(B_i)}{\sum_{j=1}^{n} P(A \mid B_j) P(B_j)}$$

贝叶斯公式用先验概率和似然更新后验概率。计算时必须保留每个事件的条件和来源，避免把 P(A | B) 与 P(B | A) 混淆。

## 5. 独立性与常见误区

定义 5.1：若 P(A ∩ B) = P(A)P(B)，则事件 A 与 B 相互独立。独立性不能与互斥性混为一谈；非零概率的互斥事件通常不独立。

注意：条件概率的分母必须严格大于零。若 P(B) = 0，则 P(A | B) 在该定义下没有意义，不能通过代数变形静默略过分母条件。
