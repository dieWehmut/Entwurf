# Changelog

## Unreleased — v0.1 prototype

- Initial Rust workspace, JSON Schema drafts, compiler/validation prototype and internal acceptance tool.
- React/Vite five-page workbench prototype and Tauri native command shell.
- C# Windows bridge scaffold and protocol tests; automation and desktop sidecar integration are not release-ready.
- Apache-2.0 project license, bundled font notices and contribution/security guidance.
- Windows PowerShell prerequisite detection, test and build entry points; local Tauri CLI dependency.
- SQLite WAL project storage, immutable IR snapshots, recovery mirrors and verified source deduplication.
- Embedded offline schemas and schema-generated TypeScript/Rust runtime contracts with drift and legacy snapshot checks.
- Current-user named-pipe JSON-RPC bridge with one-time bootstrap authentication,
  package-aware read-only discovery, responsive cancellation and artifact watching;
  real ChatGPT automation remains unavailable.
- CommonMark/LaTeX ingestion, pinned PDFium page extraction and image/scanned-page
  OCR with exact source ranges, persistent diagnostics and explicit review gates.

No production release or complete native end-to-end acceptance is asserted by this changelog. Track remaining work and release criteria in [the v0.1 plan](docs/plans/entwurf-v0.1.md).
