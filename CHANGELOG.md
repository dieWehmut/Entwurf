  real ChatGPT automation remains unavailable.

  OCR with exact source ranges, persistent diagnostics and explicit review gates.

  SVG/vector PDF export, 300 DPI PNG and verified per-version artifact manifests.

  review, version comparison, rollback and TaskEnvelope/ResultEnvelope handoff.
- Durable three-round visual repair budget and selected repair undo preserving
  exact knowledge; provenance and formula checks block unreviewed exports.
- Knowledge IR reimport into empty tasks with verified project-owned sources;
  compatible GPT group/page proposals applied with explicit fallback warnings.
- Offline diagnostic export with fixed, redacted fields; bundled dependency
  inventory and notices generated from the locked release dependency closure.
- User-provided icon bundled as PNG and multi-resolution Windows ICO.
- Native NSIS installation and repeatable installed-app acceptance harness.
