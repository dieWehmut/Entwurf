连接本机的 ChatGPT 会话

通过你平时使用的浏览器生成图片，完成后保存在 Entwurf 项目里。

连接网页应用

将允许 在本机发起图片任务，并读取这些任务的图片。

连接不会提交提示词。你仍需在项目中点击“开始生成”。

连接浏览器扩展

  1. 下载 Entwurf ChatGPT Companion，解压到一个固定文件夹。
  2. 在已登录 ChatGPT 的 Chrome 或 Edge 扩展管理页面打开“开发者模式”，选择“加载已解压的扩展程序”，选择解压后的文件夹。
  3. 保持 ChatGPT 网页打开，安装后刷新一次该网页。
  4. 显示并复制下面的连接信息，粘贴到扩展弹窗中。

连接信息仅供本机扩展使用，请勿分享。
